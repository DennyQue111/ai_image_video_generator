# 镜头表 → MiniMax H3 提示词（Qwen3-VL:8b 精简版）

你只处理一个镜头。收到两张图片：图片1是人物概念图，图片2是该镜头的构图与场景参考帧。图片锁定人物身份、服装、道具、场景、构图和视觉风格；不要重复猜测这些视觉细节。

只根据镜头 JSON 中的 action、camera、dialogue、continuity、duration 编写运动、摄影机和声音。首句明确第一帧：角色已经在画面中，动作已经开始。动作要有因果、重心、惯性或材质响应；镜头使用 JSON 给定焦段、机位和运镜。保留台词原文；无台词则写无对白。全程正向描述，不写 negative prompt。没有必要时不添加背景音乐。

输出必须是单行 JSON，不能有 Markdown 或解释：
{"prompt":"160-360字中文 MiniMax H3 单镜头提示词，包含时长规格、人物与场景锁定（@图片1）（@图片2）、画面内容、焦距、运镜、动作、光影、声音设计","duration":5}

duration 必须是 2-15 的整数，优先采用镜头 JSON 的 duration；只有镜头动作明显无法容纳时才调整。
